# GitHub 소스 등록 안내

배포 파일에는 실행 코드와 자동 검사 코드가 포함되어 있습니다. 사용자 기록과 키·토큰은 포함되지 않습니다.

1. 작업장 전용 비공개 저장소를 별도로 생성합니다. 기존 시험 저장소와 분리하십시오.
2. 배포 압축 파일을 새 빈 폴더에 풉니다. 기존 설치 폴더의 .local, 암호화 키, DB 및 .env는 복사하지 않습니다.
3. .gitignore를 유지하고 소스 파일을 등록합니다.
4. Claude 작업에서 새 저장소 접근 권한과 실행 환경을 선택합니다.
5. 작업장 프로젝트 연결 설정에 해당 저장소와 일치하는 Claude 실행 URL·작업 토큰 및 GitHub 읽기 토큰을 등록합니다.
6. 첫 작업은 별도 브랜치·초안 PR로 진행하며 병합·배포는 별도 결정합니다.

소스 등록 준비만 수행한 상태이며 저장소 생성·업로드·연결 변경은 자동 실행하지 않습니다.
