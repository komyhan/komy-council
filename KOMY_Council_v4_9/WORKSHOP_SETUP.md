## 평소에는 ‘작업 실행’만

왼쪽 프로젝트 선택 → ‘작업 실행’ → 안건 선택 → 지시 입력 → 범위 확인 → ‘해피에게 작업 보내기’.
연결 시험은 ‘연결 시험 예제 넣기’로 내용을 채울 수 있습니다. 이 버튼 자체는 실행하거나 API를 호출하지 않습니다.
최신 작업은 펼쳐지고 과거 작업은 날짜순으로 접혀 있습니다. 검토 의견과 해피 실행·PR 링크가 결과 안에 모입니다.

## 키·토큰은 ‘연결 설정’에 모음

① 해피 구독 제작: 저장소·Fire URL·해피 작업 전용 토큰.
② 결과 읽기: GitHub 읽기 토큰.
③ GPT 검토: OpenAI API 키.
선택 사항: 두 AI 토론용 Claude API 키와 토론 모델.

이미 저장한 비밀값은 ********와 ‘저장됨’으로 표시합니다. 실제 키를 브라우저로 다시 보내지 않으며 별표는 입력값이 아닌 표시입니다.
변경 버튼을 누르고 새 값을 넣었을 때만 교체합니다. 비워두면 유지합니다. 별표 자체를 붙여넣어 저장하려 하면 서버에서도 거절합니다.
‘연결 정보 한 번에 저장’은 API 키와 프로젝트 연결을 순서대로 저장합니다. 일부 단계 실패 시 저장된 부분과 실패한 부분을 구분해 안내합니다.
자동 검토 켜기·모델·예산은 같은 화면 아래에서 조정합니다. 기존 토론 API 비용은 이 예산과 별도입니다.

설정 보관 상태와 실제 인증·실행 성공은 다릅니다. 서버를 켜두어야 작업장 감시와 GPT 검토가 실행됩니다.
지시 초안은 탭 이동·설정 저장 시 메모리에서 유지하지만 브라우저 종료·새로고침 후 유지되는 영구 저장은 아닙니다.

# KOMY v4.5 — 구독 제작과 자동 검토

## 역할

- 작업장: 프로젝트별 안건·방향·토론·컨펌 기록과 작업 요청.
- Claude Code 공식 클라우드 작업: 구독 사용량 내에서 제작과 시험, 초안 PR 작성. 구독 한도·추가 사용 결제는 Claude 계정에서 확인한다.
- GPT API: 작업과 연결된 PR의 변경 코드, 전달한 지시, GitHub CI 상태 보고 검토. 실제 코드를 실행하는 검증기가 아니며 전체 저장소를 읽는 것도 아니다.
- 사람: 계산 기준, 권한, 지출, 실제 회사 데이터, main 병합·배포 결정.

## 설치

기존 서버 창을 닫고 원래 폴더에 압축을 풀어 덮어쓴다. `.local` 폴더는 지우지 않는다. Start-KOMY.cmd 실행 후 브라우저 Ctrl+F5. 왼쪽 ‘구독 제작·자동 검토’를 연다.

## 최초 연결

1. https://claude.ai/code/routines 에서 Claude 구독 계정으로 작업을 만든다. 이 프로젝트 GitHub 저장소를 연결한다. 화면에 제공하는 고정 프롬프트를 붙여 넣는다.
2. 처음에는 시간 예약을 추가하지 않고 API 트리거만 추가한다. Fire URL과 그 작업 전용 토큰을 작업장에 저장한다. 이 토큰은 일반 Claude Platform API 키가 아니다.
3. 저장소를 `owner/repo` 형식으로 입력한다. 비공개 저장소는 해당 저장소의 Pull requests·Contents·Commit statuses 읽기 권한을 가진 GitHub 토큰도 저장한다.
4. OpenAI 키는 기존 AI 연결 화면에서 등록한다. 자동 검토 화면에서 예산을 확인하고 외부 전송·과금 안내를 확인한 뒤 자동 검토를 켠다.
5. 안건을 선택하고 허용하는 작업·시간·데이터·시험 범위를 적은 뒤 ‘최신 지시로 해피 작업 시작’을 누른다. 처음에는 가상 자료의 작은 변경, 최대 30분·초안 PR 1개로 시험한다.

Claude 계정의 예약 작업 제공 여부와 구독·추가 사용 결제 설정은 앱이 대신 확인할 수 없다. 최초 연결은 사용자가 본인 계정에서 완료해야 한다. 이 버전은 실제 계정으로 유료 연결 시험을 수행하지 않았으며 모의 응답으로 연결 흐름을 검증했다.

## 자동으로 하는 일

전송 버튼을 누를 때 최신 프로젝트 자료, 안건의 의견·결정, 최근 토론, 이전 GPT 검토를 사본으로 고정해 Claude 작업에 보낸다. 요청별 고유 marker를 초안 PR 본문에 남기도록 지시한다. 서버는 1분마다 열린 PR 최대 100개에서 그 marker를 찾아 변경 코드와 CI 상태를 수집한다. 코드·기준 브랜치 버전이 수집 중 변경되면 다음 확인까지 보류한다. 진행 중인 CI가 있으면 기다린다. 시험 보고가 없으면 실행된 시험이 없는 상태로 검토 자료에 전달하며 통과로 만들지 않는다.

GPT 자동 검토는 처음에는 꺼져 있다. 사용자가 켜면 같은 PR 커밋·고정 지시 버전을 한 번만 검토한다. 코드가 바뀌면 최대 3회까지 새 버전을 검토한다. 검토 결과와 과금 사용량, 커밋 SHA, 고정 지시 버전을 저장한다. 과금 미확인·출력 중단도 자동 재시도하지 않는다.

## 다음 날

작업장에서 결과를 읽고 의견·컨펌을 기록한다. 기록 저장만으로 Claude가 실행되지는 않는다. 기존 요청의 감시를 종료한 뒤 최신 지시를 새 작업으로 보낸다. 새 지시에는 이전 검토 결과도 포함된다. ‘감시 종료’는 로컬 PR 감시만 종료한다. 진행 중인 Claude 클라우드 세션은 그 세션에서 따로 중지해야 한다.

작업장 지시 버전이 변경되면 기존 요청의 GPT 검토를 멈춘다. 이전 검토를 새 지시에 대한 승인처럼 사용하지 않는다. GPT 지적을 해피가 자동으로 반복 수정하는 기능, 사람의 최종 승인 자동 처리, 병합·배포는 구현하지 않았다.

## 비용과 보관

자동 검토 기본값은 하루 $1·월 $10·하루 10회, mini 모델이다. 날짜는 UTC 기준이다. 입력 전체 UTF-8 바이트 수 + 2,048과 출력 상한 3,000토큰으로 보수적인 최대 예상액을 예약하고 한도를 확인한 다음 호출한다. 응답의 실제 입력·출력 사용량으로 정산한다. 미확인 호출은 예약액을 계속 잡아 둔다. 추론 토큰은 출력 사용량에 포함된다. 이 예산은 자동 코드 검토만 제어하며 기존 토론·다른 앱·Claude의 별도 청구액은 포함하지 않는다.

Windows DPAPI로 프로젝트별 Claude 작업 토큰·GitHub 읽기 토큰을 `.local/bridge.dpapi`에 저장한다. 토큰은 작업 사본·화면·배포 파일에 포함하지 않는다. `.local/council.db`에는 코드 diff를 포함한 검토 지시 사본 대신 고정 작업 사본·검토 보고·사용량이 남으며, 코드 diff는 OpenAI 검토 요청에 전송한다. 로컬 서버는 켜져 있어야 지시 전송·감시·GPT 검토가 실행된다. 이미 전달한 Claude 클라우드 작업은 PC를 꺼도 별도로 실행될 수 있다.

## v4.5 Checks 조회 수정

Fine-grained 토큰은 Checks API를 지원하지 않으므로 해당 API를 호출하지 않는다. Contents·Pull requests·Commit statuses 읽기 권한만 사용한다. GitHub 커밋 상태 보고만 수집하며 진행 중이면 기다린다. Checks 시험은 항상 미확인으로 보고하고 상태 보고 없음·코드 검토 완료를 시험 통과로 표시하지 않는다. 실제 CI 시험 확인은 PR의 Checks 화면에서 별도로 해야 한다.
