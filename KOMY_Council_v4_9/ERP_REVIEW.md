## 3. 파일럿 실행 순서

1. **Seaover 내보내기 샘플 확보.** 품목·규격·단위, 창고·로트별 수량, 예약, 입출고와 원거래 식별자가 나오는지 확인한다. 예약이나 담보 제한을 확보할 수 없으면 해당 수량은 미확인으로 표시한다. 확정 가용재고를 표시할 수 있는지부터 판단한다.
2. **실제 거래 하나를 끝까지 추적.** 수입 → 통관 → 입고 → 예약 → 부분출고 → 비용 추가 → 월말 마감의 단계마다 어느 자료가 기준인지 기록한다. 자사 상대 0원 매출은 원거래와 짝을 확인한 뒤 분류한다.
3. **한 품목군으로 화면 검증.** 거래가 꾸준하고 부분출고·이동을 볼 수 있으며 담당자가 검증할 수 있는 품목을 고른다. 첫 화면에 창고·로트별 수량, 가용량의 근거, 출고 지시와 실제 출고의 차이, 마지막 정상 동기화 시각을 표시한다.
4. **예외 거래를 재현.** 예약 취소, 부분출고, 창고 이동, 반품, 정정, 동일 자료 재수집, 동기화 지연을 재현한다. 이후 직접 기록을 검토할 때는 두 직원이 마지막 재고를 동시에 출고하는 상황도 시험한다.
