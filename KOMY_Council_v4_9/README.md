# KOMY 작업장 v4.9

## 화면 용어 정리

메뉴, 작업 요청, 검토, 결정, 설정 및 안내 문구를 공식 프로그램 문체로 정리했습니다.
예: 작업 현황 / 검토 대기 / 결정 저장 / Claude 실행 내역 / 코드 변경 내역(PR).
사용자가 입력한 기존 내용, AI 보고서 원문 및 저장된 자료는 변경하지 않습니다.
앞으로 작성되는 GPT 검토에는 정식 보고서 문체를 사용하도록 지침을 적용했습니다.

## 레이아웃 및 상태 안내

작업 지시 접기 항목과 실행 버튼을 별도 영역으로 분리했습니다. 실행·PR 버튼에 최소 높이, 여백 및 줄바꿈을 적용했습니다.
종료된 작업은 이전 재전송 경고 대신 기존 결과 보관 안내를 표시합니다. 저장된 오류 원문은 변경하지 않습니다.
86개 자동 검사 통과. 문제 구간은 브라우저 예제 화면으로 시각 확인했습니다. 실제 사용자 설치 환경 전체 및 유료 API 재실행은 검증하지 않았습니다.

## 설치

기존 서버 창 종료 → 같은 폴더 덮어쓰기 → .local 유지 → Start-KOMY.cmd 실행 → Ctrl+F5.
기존 키·토큰 및 기록을 유지합니다.
GitHub 소스 등록 준비는 GITHUB_SETUP.md를 참조하십시오. 실제 저장소 생성·업로드·연결 변경은 실행하지 않았습니다.
